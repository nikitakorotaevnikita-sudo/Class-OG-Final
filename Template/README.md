# Шаблон проекта для разработки прототипов

Этот репозиторий — готовый каркас для быстрой проверки продуктовых гипотез и создания MVP. Он помогает запустить разработку, собрать требования, спроектировать архитектуру, реализовать решение и проверить его в Docker с автотестами.

## 🎯 Когда использовать

Подходит для:
- Быстрой проверки гипотез и MVP
- Прототипов AI‑приложений
- Проектов с понятными бизнес‑целями

Не подходит для:
- Production‑решений без последующей доработки
- Проектов без четкой гипотезы

## 📁 Что внутри

- `.hypothesis/` — постановка задачи и результаты этапов
- `src/` — исходный код приложения
- `tests/` — автотесты (unit/integration/e2e)
- `data/` — данные и артефакты (если нужны)
- `.env` — рабочая конфигурация запуска

## 🚀 Как начать разработку

1. Заполните `.hypothesis/00_HYPOTHESIS.md` (что за продукт, для кого, как измеряем успех).
2. В Claude Code запустите `/pm` — Project Manager запустит pipeline.
   Если хотите авто-режим: `/pm MODE: AUTO`
3. Ответьте на вопросы по гипотезе и дождитесь готового прототипа.
4. Запускайте собранное решение через Docker.

## ⚙️ Окружение

Для запуска нужен файл `.env` с параметрами:
- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `OPENAI_SERVER` (опционально, если используется нестандартный адрес)

## 🧪 Запуск прототипа

После завершения разработки запускайте через Docker:
```
docker-compose up
```
