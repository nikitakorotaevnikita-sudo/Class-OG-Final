# Полный перечень рубрик классификатора (вариант B)

## Назначение

Вариант B ручной проверки: вместо поиска `classifier_search` агент выбирает код
прямо из полного перечня рубрик. Оператор сравнивает его с вариантом A (поиск
топ-50) по точности и времени.

## Файл

`classifier_full.txt` в этом навыке — все рубрики, которые можно поставить
обращению: 1876 строк, уровни 4 и 5 классификатора. Формат строки:

```
КОД — Раздел / Тематика / Тема / Вопрос
```

## Как пользоваться

1. Прочитай `classifier_full.txt` целиком, а не первые строки.
2. **Сначала тема, потом код.** Для каждого вопроса выбери тему — третью ступень
   (`XXXX.XXXX.XXXX`), затем конкретный код этой темы: четвёртой ступени или
   уточняющий пятой, если в тексте есть подробность, которую он уточняет.
3. **Типовые разграничения:**
   - `0096` / `0097`: новое строительство и реконструкция → `0096`; ремонт и
     благоустройство → `0097`;
   - `0007` / `0014`: пенсии, льготы, социальный работник → `0007`; лекарства,
     поликлиники, медицинская помощь → `0014`;
   - `0004` / `0013`: опека, алименты, материнский капитал → `0004`; детский сад,
     школа, поступление → `0013`;
   - ЖКХ `0005.0005.0056` / инфраструктура поселений `0003.0009.0097`: проблема внутри
     дома, с управляющей компанией или ТСЖ, начислениями, внутридомовыми сетями → ЖКХ;
     сети и объекты поселения в целом → `0003.0009.0097`;
   - автодороги `0003.0009.0099` / благоустройство `0003.0009.0097`: дороги, улицы,
     трассы → `0003.0009.0099`; дворы, придомовые территории, тротуары →
     `0003.0009.0097`.
4. **История заявителя.** Коды прошлых обращений того же заявителя по той же теме
   (навык `og-repeat`) — сильная подсказка, но код выбирай по тексту текущего
   вопроса. На какие обращения опирался — в `check.history_used`.
5. **Код — только из файла, дословно.** Кода нет в файле — его нет в классификаторе.
   Проверь выбранный код `classifier_get`: нужны `exists = true` и ступень 4 или 5.
6. **Три альтернативы** в `check.alternatives`: сосед в той же теме; лучший код из
   другой правдоподобной темы; для кода пятой ступени — его родитель четвёртой.
7. **Нельзя:** один код на разные вопросы; «прочее» `0001.0002.0027.0126`, когда в
   файле есть более точная рубрика.

## Контрольный вопрос (для оператора)

Перед сравнением вариантов оператор спрашивает агента: сколько рубрик в файле и
какие три кода в его конце. Правильный ответ — 1876 рубрик и три последние строки
файла. Не знает — файл до модели целиком не доходит (обрезается или идёт через
поиск по фрагментам), и сравнение вариантов A и B не имеет смысла.
