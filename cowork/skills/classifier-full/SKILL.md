# Полный перечень рубрик классификатора (вариант B)

## Назначение

Вариант B ручной проверки: вместо поиска `classifier_search` агент выбирает код
прямо из полного перечня рубрик. Оператор сравнивает его с вариантом A (поиск
топ-50) по точности и времени.

## Файл

`classifier_full.txt` в этом навыке — все рубрики, которые можно поставить
обращению: 1876 строк, уровни 4 и 5 классификатора. Формат строки:

```
КОД — Раздел / Тематика / Тема / Вопрос
```

## Как пользоваться

1. Прочитай `classifier_full.txt` целиком, а не первые строки.
2. Для каждого вопроса выбери тему, затем код — по тем же правилам, что в навыке
   `classifier-code` (типовые разграничения, история заявителя, три альтернативы).
3. Код бери только из файла, дословно. Кода нет в файле — его нет в классификаторе.
4. Если доступен `classifier_get` — проверь выбранный код и им.

## Контрольный вопрос (для оператора)

Перед сравнением вариантов оператор спрашивает агента: сколько рубрик в файле и
какие три кода в его конце. Правильный ответ — 1876 рубрик и три последние строки
файла. Не знает — файл до модели целиком не доходит (обрезается или идёт через
поиск по фрагментам), и сравнение вариантов A и B не имеет смысла.
