# Подбор кода классификатора

## Назначение

Главный шаг: здесь решается точность классификации. Для каждого вопроса ты получаешь
кандидатов из поиска по классификатору и выбираешь один код. Выдуманный или неверный
код уйдёт в Directum RX и в статистику обращений.

## Порядок для каждого вопроса

1. **Перескажи вопрос языком классификатора.** Граждане пишут бытовыми словами, а
   рубрики сформулированы канцелярским языком органов власти. Составь запрос из трёх
   частей:
   - суть вопроса одной фразой;
   - 5–8 ключевых фраз: сфера, объект, действие;
   - 3–6 официальных формулировок, как их пишут в классификаторе.

   Пример: «муж вернулся из зоны СВО, выплаты не получены» → «Выплаты участникам
   специальной военной операции. Социальная поддержка военнослужащих, единовременная
   выплата, ветеран боевых действий. Выплаты за участие в боевых действиях, меры
   социальной поддержки участников СВО».

2. **Найди кандидатов:** `classifier_search(query, top_k=50)`. В ответе — до 50 рубрик
   с кодом, названием, полным путём и оценкой близости. Оценка — подсказка, а не
   решение: первая по оценке рубрика не обязательно верная.

3. **Если подходящей тематической ветки среди кандидатов нет** (вопрос о
   здравоохранении, а в выдаче только ЖКХ и соцобеспечение) — переформулируй запрос
   другими синонимами или шире по теме и ищи ещё раз. Не больше двух повторов. Не
   нашлось и после них — выбери ближайший код, поставь `check.needs_verification =
   true` и напиши об этом в `reasoning`.

4. **Сначала тема, потом код.** Выбери тему вопроса — третью ступень
   (`XXXX.XXXX.XXXX`), затем конкретный код этой темы. Код — четвёртой ступени или
   уточняющий пятой, если в тексте есть подробность, которую он уточняет.

5. **Типовые разграничения:**
   - `0096` / `0097`: новое строительство и реконструкция → `0096`; ремонт и
     благоустройство → `0097`;
   - `0007` / `0014`: пенсии, льготы, социальный работник → `0007`; лекарства,
     поликлиники, медицинская помощь → `0014`;
   - `0004` / `0013`: опека, алименты, материнский капитал → `0004`; детский сад,
     школа, поступление → `0013`;
   - ЖКХ `0005.0005.0056` / инфраструктура поселений `0003.0009.0097`: проблема внутри
     дома, с управляющей компанией или ТСЖ, начислениями, внутридомовыми сетями → ЖКХ;
     сети и объекты поселения в целом (водоснабжение посёлка, уличные колонки,
     магистрали) → `0003.0009.0097`;
   - автодороги `0003.0009.0099` / благоустройство `0003.0009.0097`: дороги общего
     пользования, улицы, трассы — их состояние, содержание, расчистка снега →
     `0003.0009.0099`; дворы, придомовые территории, тротуары → `0003.0009.0097`.

6. **История заявителя.** Если навык `og-repeat` нашёл прошлые обращения этого
   заявителя по той же теме, их коды — сильная подсказка. Но код выбирай по тексту
   текущего вопроса: тема могла смениться. На какие прошлые обращения опирался —
   запиши их регистрационные номера в `check.history_used`.

7. **Проверь код:** `classifier_get(code)`. Нужны `exists = true` и ступень 4 или 5.
   Не подтвердился — возьми следующего кандидата. Код, который не вернул
   `classifier_search` и не подтвердил `classifier_get`, в ответ не идёт.

8. **Три альтернативы** в `check.alternatives` для каждого выбранного кода:
   - сосед в той же теме — на случай, если тема верна, а конкретный код нет;
   - лучший кандидат из другой правдоподобной темы — на случай, если неверна тема;
   - для кода пятой ступени — его родитель четвёртой, иначе ещё один сильный
     кандидат.

## Нельзя

- Один код на разные вопросы. Получилось так — значит, это один вопрос.
- Код «прочее» `0001.0002.0027.0126`, когда среди кандидатов есть более точный.
- Код, которого нет в выдаче `classifier_search`.

## Если классификатор не отвечает

`classifier_search` или `classifier_get` вернул таймаут, «Классификатор недоступен»,
ошибку или пустой ответ — повтори вызов один раз. Не помогло — прекрати подбор кодов
и верни ошибку по правилу системной инструкции: `check.error` =
`"Классификатор недоступен: <инструмент> — <что он вернул>"`, коды вопросов `null`.
Не переходи на навык `classifier-full` и не подбирай код по памяти.

## Инструменты

`classifier_search(query, top_k=50)` и `classifier_get(code)` — сервер mcpOGV.
