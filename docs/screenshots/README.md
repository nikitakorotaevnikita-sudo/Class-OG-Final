# Скриншоты веб-интерфейса

Сюда добавить:

1. `01_input_form.png` — главная страница с формой ввода
2. `02_classification_result.png` — результат классификации с кнопками верификации

## Как сделать скриншот

1. Запустить `launch.bat → [3] Start API server`
2. Открыть браузер на http://localhost:8000
3. Выбрать пример «Жалоба на вывоз мусора» и нажать «Классифицировать»
4. Сохранить скриншот формы ввода → `01_input_form.png`
5. Сохранить скриншот результата с кодами и кнопками → `02_classification_result.png`
6. Скопировать файлы в эту папку (`docs/screenshots/`)
7. Раскомментировать строки с изображениями в `README.md` (секция «Веб-интерфейс»)
