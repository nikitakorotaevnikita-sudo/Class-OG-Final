# Запрос сессии MCP: новый тул поиска по классификатору в mcpOGV

Дата: 04.11.2026 · От: сессия Class OG · Кому: сессия MCP (репозиторий

## Зачем

Решение оператора (04.11.2026): у агента-классификатора в ArioCowork один MCP —
mcpOGV. Поиск кандидатов остаётся нашим; для агента он становится новым тулом
mcpOGV, который вызывает HTTP-точку сервиса классификатора. Такого тула в mcpOGV
пока нет.

Схема: агент → mcpOGV `classifier_search` → HTTP → сервис классификатора (эмбеддинги
+ лексика) → топ-50 рубрик → агент сам выбирает финальный код по навыку
`classifier-code` с учётом истории заявителя (`og-repeat`).

Спецификация: `docs/superpowers/specs/2026-10-29-cowork-classifier-agent-design.md`,
§8.1–8.2 (Class-OG-Final, ветка `research/quality-followups-68`).

## Контракт HTTP-точек (делает Class OG, ветка `int-og`)

### `POST {CLASSIFIER_URL}/integration/candidates`

Тело:

```json
{"query": "фраза языком классификатора", "top_k": 50}
```

Ответ 200:

```json
{"items": [{"code": "0004.0015.0158.0974", "name": "…", "level": 4,
            "full_path": "… / …", "score": 0.61}],
 "returned": 50}
```

- `top_k` приводится к 1…50 (не 422).
- Пустой `query` → 400 `{"detail": "…пуст…"}`.
- Сервис ещё грузит модель → 503 `{"detail": "Агент не инициализирован"}`.

### `GET {CLASSIFIER_URL}/integration/classifier/{code}`

- 200 `{"code", "name", "level", "full_path", "parent_code", "exists": true}`.
- Неизвестный код → 200 `{"code": "…", "exists": false}`.
- Код нормализуется: пробелы обрезаются, короткий дополняется `.0000` до четырёх
  сегментов (`0003.0009.0097` → `0003.0009.0097.0000`), L5 (пять сегментов) — как есть.

Авторизации у точек нет — как у остальных `/integration`: только внутренняя сеть,
отдаются данные классификатора, не ПДн. Логи — без текста запроса.

## Что просим в mcpOGV

- `classifier_search(query: str, top_k: int = 50)` — вызывает `POST /integration/candidates`,
  отдаёт `items` агенту как есть.
- `classifier_get(code: str)` — вызывает `GET /integration/classifier/{code}`.
- Оба — только чтение (`READ_ONLY`), без учётки RX.
- Адрес сервиса — настройка mcpOGV (например `CLASSIFIER_URL`). На стенде — машина
  `governmentgenai` = `172.16.104.68`, порт 8010 или 8020 (если 8010 занят mcpOGV —
  пока не проверено).
- 400 и 503 от точки → понятная `ToolError` агенту; таймаут или отказ соединения →
  `ToolError` «классификатор недоступен».
- Описание тула для модели: искать фразой языком классификатора (суть + ключевые
  фразы + официальные формулировки); код из выдачи перед ответом проверять
  `classifier_get`.
