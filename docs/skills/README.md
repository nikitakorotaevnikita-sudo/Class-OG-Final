# Собранные навыки агентов Class OG для ArioCowork

Готовые к загрузке архивы навыков: по `ИМЯ.zip` и `ИМЯ.skill` на каждый (содержимое
одинаковое, `SKILL.md` — в корне архива). Упаковка — по тем же правилам, что у навыков
mcpOGV (репозиторий `MCP-Directum-RX`, `docs/skills/`). Исходники — `cowork/skills/<имя>/`,
сборка агента в Cowork — `cowork/README.md`.

Загрузка в LibreChat: раздел навыков → загрузить `.zip` (или `.skill`) → подключить навык
к агенту.

## Агент «Классификатор обращений»

| Навык | Назначение |
|---|---|
| `appeal-questions` | Выделение вопросов из обращения |
| `applicant-contacts` | ФИО и email заявителя |
| `classifier-code` | Подбор кода классификатора по топ-50 из `classifier_search` (вариант A) |
| `classifier-full` | Полный перечень 1876 рубрик вместо поиска (вариант B), с файлом `classifier_full.txt` |

Готовые навыки из mcpOGV, которые подключаются к этому агенту: `og-repeat`.

## Агент «Ответы на обращения граждан»

| Навык | Назначение |
|---|---|
| `answer-practice` | Практика ответов органа по коду вопроса: поиск с расширением до темы и 12 месяцев, отбор отписок, ключевые пункты, рег. номера-источники |
| `answer-legal-basis` | Нормы из КонсультантПлюс (mcp-pravo) с реквизитами; ссылки только на найденное |
| `appeal-questions`, `classifier-code`, `applicant-contacts` | те же, что у классификатора; два последних — только когда нет карточки или вопросов в ней |

Готовые навыки из mcpOGV, которые подключаются к этому агенту: `og-repeat`, `og-letters`,
`og-answer-review`. Инструкция агента — `cowork/answer-agent/agent-instruction.md`.

## Обновление

Архивы пересобираются из исходников прямо сюда:

```bash
venv\Scripts\python scripts\build_cowork_skills.py
```

Сборка детерминирована: одинаковые исходники дают одинаковые байты. Тест
`tests/test_build_cowork_skills.py::test_published_archives_match_sources` падает, если
исходник навыка поменяли, а архив здесь не пересобрали.
