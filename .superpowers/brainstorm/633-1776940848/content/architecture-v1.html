Целевая интеграция

Directum RX 25.3
Карточка обращения гражданина
Оператор вводит текст обращения
↓ Вызов API
API: POST /classify
http://localhost:8000/classify
↓
AI Classifier (этот проект)
→ Код + Вид + Подвопрос → Возврат в Directum
↓
Directum заполняет поля: Вид, Вопрос, Подвопрос, Предмет ведения

Как видим сценарий:

  1. Оператор создаёт карточку обращения в Directum RX
  2. Вставляет текст обращения → нажимает "Классифицировать"
  3. Directum вызывает POST /classify нашего агента
  4. Агент возвращает: вид, вопрос, подвопрос, предмет ведения, уверенность
  5. Directum заполняет поля карточки → оператор верифицирует

Откройте http://localhost:56722 в браузере и нажмите "Начать". Запустим сессию!
